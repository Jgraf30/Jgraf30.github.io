Overview

What It Does

REDCap is a widely used research data capture platform in healthcare and academic environments — but standing it up securely on Azure at enterprise scale requires infrastructure that's both locked down and repeatable. This project solves that with two deployment paths: ARM Templates for one-click provisioning and Terraform for teams that need full IaC lifecycle management and reusable module patterns.

The architecture goes beyond a basic PaaS lift — it implements private endpoints, hub/spoke network topology, Key Vault integration for secrets management, and Ansible automation for workstation configuration. The result is a deployment you can hand to a regulated research or healthcare organization and trust it meets enterprise security and compliance requirements out of the box.
