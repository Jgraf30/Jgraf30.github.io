Overview

What It Does

Most RAG tutorials give you a notebook that calls an API and calls it done. This is the other thing — a complete, self-contained system you can actually run, extend, and deploy. It handles the full pipeline: document ingestion, chunking, embedding, vector storage, retrieval, context injection, and grounded response generation with citations back to the source material.

The "no API key required" design matters. Deterministic demo embeddings let you develop, test, and demo the full system without touching OpenAI — then swap in real embeddings for production quality with a single environment variable. Two interfaces are included out of the box: a FastAPI backend for programmatic access and a Streamlit UI for interactive Q&A.

Quick Start

Get Running in 5 Steps

bash 
# 1) Create and activate virtual environment
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt

# Optional: plug in OpenAI for production-quality answers
# export OPENAI_API_KEY=sk-...

# 2) Drop your PDFs or TXT files into ./data
mkdir -p data && cp your.pdf data/

# 3) Build the vector store
python rag.py ingest --data data --store store

# 4) Ask a question from the CLI
python rag.py ask --store store --q "What is the main finding?"

# 5a) Or run the REST API
uvicorn app:app --reload

# 5b) Or launch the Streamlit UI
streamlit run ui.py

Capabilities

Key Features

📦
Zero API Key Required
Deterministic demo embeddings let you run the full pipeline locally — no OpenAI account, no costs, no rate limits during development.
🔌
OpenAI Drop-In
Set one environment variable and the system switches to real OpenAI embeddings and completions. Same code, production-quality output.
🖥️
Streamlit UI
Interactive document Q&A interface — upload docs, ask questions, read answers with inline citations. No frontend code required.
⚡
FastAPI Backend
REST API for programmatic access — ingest endpoints, query endpoints, JSON responses. Integrate with any downstream system.
📎
Grounded Citations
Every answer includes citations back to the source chunks — no hallucinations about where the answer came from.
🧩
Fully Self-Contained
Local vector store, no external database required. Clone, install, run. The entire system fits in one repo with no managed services needed.
