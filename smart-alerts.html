01 / Problem

SharePoint Alerts
are going away

Microsoft is phasing out native SharePoint alerts. Organizations relying on them need a replacement — one that actually improves on what they had.

SharePoint native alerts
  • Being deprecated — no long-term viability
  • No smart filtering — every change triggers a notification
  • Email only — no Teams integration
  • No digest mode — inbox floods on active lists
  • No visibility — admins can't see what alerts exist
  • Hard for users to manage — buried in list settings
  • No natural language — users must configure field-level rules manually
Smart Alerts replaces all of this
  • Built on Power Platform — fully supported, extensible
  • AI filters noise — only significant changes notify
  • Teams + email delivery with rich adaptive cards
  • Immediate or daily digest mode, per subscription
  • Admin dashboard — full visibility across the org
  • Self-service Power Apps UI — no list settings required
  • Natural language subscriptions — "alert me when a high-priority item is assigned to me"

03 / Features

What makes it different

The AI layer is the core differentiator. Everything else is infrastructure.

F-01
Natural language subscriptions
Users describe what they want to be alerted on in plain English. AI Builder parses the description into structured filter conditions — no field configuration required. "Alert me when a contract over $50K is submitted for review" just works.
F-02
AI significance scoring
Every change is scored 0–100 for significance against the user's criteria. Users set their own threshold. Low-signal noise is suppressed, logged, and available to review — but it doesn't hit their inbox.
F-03
Plain-English change summaries
Instead of a raw field-change dump, notifications include an AI-written summary of what actually changed and why it matters. Written for the business user, not the system admin.
F-04
Teams adaptive card notifications
Structured cards in Teams channels with the AI summary, change metadata, significance score, and direct action buttons — view item and manage alerts — no inbox required.
F-05
Daily digest mode
Users who prefer a single daily summary instead of immediate notifications get one AI-composed digest covering all changes from the past 24 hours, grouped by list and priority.
F-06
Full admin visibility
Admin screen shows all subscriptions across the organization, notification volumes, and per-list activity. Admins can deactivate any subscription and export a governance report without touching SharePoint settings.

05 / AI Prompts

The intelligence layer

Three GPT prompt actions in AI Builder handle all AI processing. All prompts return structured JSON for reliable parsing in Power Automate.

SYSTEM: You are a SharePoint change notification assistant. Your job is to summarize what changed on a SharePoint item and evaluate whether the change is significant enough to notify a user, based on their subscription criteria. Always respond with valid JSON only. No preamble, no markdown. USER: Change type: @{variables('ChangeType')} Item title: @{triggerBody()?['d/Title']} Changed by: @{triggerBody()?['d/Editor/Name']} List name: @{variables('ListName')} Fields changed: @{variables('ChangedFieldsSummary')} User subscription: "@{items('Apply_to_each')?['nl_description']}" Parsed criteria: @{items('Apply_to_each')?['parsed_conditions']} Respond with: { "ai_summary": "2-3 sentences, plain English, what changed and why it matters", "significance_score": 0-100, "significance_reason": "brief explanation" }
SYSTEM: You are a Power Platform configuration assistant. Convert a user's plain-English SharePoint alert description into structured filter conditions. Always respond with valid JSON only. USER: User's description: "@{triggerBody()?['nl_description']}" Available list fields: @{variables('FieldSchemaString')} Respond with: { "trigger_events": ["created", "modified", "deleted"], "conditions": [ { "field": "InternalFieldName", "operator": "equals | contains | greater_than | less_than | not_equals", "value": "comparison value" } ], "plain_english_summary": "One sentence — what this alert watches for", "confidence": 0-100 }
SYSTEM: You are a SharePoint activity digest assistant. Summarize multiple SharePoint change events into a concise daily digest. Write in plain English. Use bullet points. Lead with the most important changes. USER: Create a daily digest for @{variables('UserName')} covering @{variables('EventCount')} SharePoint changes from the past 24 hours. Events: @{variables('AllChangeSummaries')} Write a digest that: — Opens with a one-sentence overview — Lists each significant change as a bullet — Groups by list name if 3+ changes from the same list — Ends with a count of suppressed low-significance events — Stays under 300 words
